## Rollback Instructions

If consolidation breaks something:

```powershell
# 1. Stop orchestrator
Stop-Process -Name "python" -ErrorAction SilentlyContinue

# 2. Restore DBs
Copy-Item "C:\Users\Couch\dev\ai-orchestrator\.runtime\orchestrator\state.sqlite.backup" `
          "C:\Users\Couch\dev\ai-orchestrator\.runtime\orchestrator\state.sqlite" -Force

# 3. Restore governor runtime
Remove-Item "C:\Users\Couch\.ai-resource-governor\inventory.sqlite" -Force
Copy-Item "C:\Users\Couch\.ai-resource-governor\inventory.sqlite.backup" `
          "C:\Users\Couch\.ai-resource-governor\inventory.sqlite" -Force

# 4. Restore code (if needed)
cd C:\Users\Couch\dev\ai-orchestrator
git checkout -- orchestrator/governance/
git checkout -- data/rosters/worker_roster_v2.json
```

**Backup Locations:**
- DB: `.runtime/orchestrator/state.sqlite.backup`
- Worker roster: `data/rosters/worker_roster_v2.json.backup`
- Governor DB: `.ai-resource-governor/inventory.sqlite.backup`
